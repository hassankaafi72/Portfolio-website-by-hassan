# Hassan Abdifatah Mohamud — Portfolio

Personal portfolio site for Hassan Abdifatah Mohamud, Full-Stack Web Developer, Machine Learning Engineer, and Content Strategist. Built with React, TypeScript, Tailwind CSS, and Lucide icons.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- lucide-react icons

## Getting Started

```bash
npm install
npm run dev
```

```bash
npm run build   # type-check + production build
npm run lint    # oxlint
npm run preview # preview the production build
```

## Configuration

Before deploying, update the placeholder values in `src/data/config.ts`:

- `GITHUB_URL`
- `LINKEDIN_URL`
- `EMAIL_ADDRESS`
- `RESUME_URL`
- `PROFILE_IMAGE_URL`

## Project Structure

```
src/
  components/   Section components (Navbar, Hero, About, Skills, Projects, ...)
  context/      Theme (dark/light) context
  data/         Site content and configuration (skills, projects, nav, config)
```
